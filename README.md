# Neha Herbals — website concept

A premium, single-page website concept for **Neha Herbals** — herbal henna &
personal care, *herbal goodness since 1992*.

- Static site — just `index.html` + `assets/` (no build step).
- Elegant, mobile-first design aligned to the Neha Herbals identity: green + gold +
  cream palette, lotus motif, Fraunces + Jost type, cinematic hero, product cards,
  a signature-product feature with **Shop on Amazon / Blinkit** links, a lookbook
  gallery and an enquiry form.

## View locally
Open `index.html` in any browser. (Fonts load from the internet, so view online for
the full effect.)

## Deploy
Hosted with **GitHub Pages** from the `main` branch (root).

> Demo concept for presentation. Brand name, product and imagery belong to Neha Herbals.
